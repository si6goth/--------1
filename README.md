## Описание

Проект демонстрирует работу с современными инструментами разработки:

- **Git** — контроль версий, ветвление, коммиты
- **VS Code** — расширения, форматирование кода, поиск и замена
- **JavaScript** — вывод приветствия `Hello, World!`
- **Python + Faker** — генерация случайных данных (имена, адреса, email, телефоны)
- **Markdown** — документация проекта

## Установка

```bash
# Установите зависимости
pip install faker autopep8
```

## Запуск

```bash
# Запуск JavaScript-скрипта
node hello.js

# Запуск Python-скрипта
python main.py
```

## Структура проекта

```
├── .gitignore          # Игнорируемые файлы (__pycache__/)
├── README.md           # Документация проекта
├── hello.js            # Приветствие на JavaScript
├── main.py             # Генератор случайных данных (Python + Faker)
└── homework_project/   # Вложенный учебный проект
```

## Возможности

- Вывод текущей даты и времени
- Генерация случайных имён, адресов, email, телефонов
- Генерация списка фейковых пользователей
- Русская локаль для генерации данных
